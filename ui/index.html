REMOTE SERVERS

添加服务器

密码与六位验证码只在连接时于独立 SSH 窗口输入，任何地方都不会保存。删除会移除目录条目，不影响远端文件。
LOCAL ACCOUNT

登录

账号只存储在本机（scrypt 哈希），用于解锁历史对话；不同设备之间不互通。密码不会被任何地方记录。
PROJECT

新建项目

项目把对话历史按计算任务分开，打开某个项目时只显示该项目的历史。文件夹路径仅作为标识记录，程序不会读写该文件夹。
!

确认操作
CROSS-SERVER TRANSFER

服务器间传输

把文件从一台服务器拷贝到另一台。传输经 Vlab 中转节点暂存，两端路径都必须位于各自的允许根目录内，且不能是根目录本身。

填写后点击「开始传输」会先弹出确认框，批准后开始执行（大文件可能需要较长时间）。
