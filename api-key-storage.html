VASPilot · 安全更新

API Key 自动恢复

密钥以 Windows 凭据加密保存在本机，重启后只需登录，密钥自动回到内存——不再每次重填，也绝不明文落盘。

已部署 · 2026-08-14

之前

每次重启 VASPilot 都要在设置里重新粘贴 API Key，密钥只活在内存里，一关就丢。

现在

保存的密钥用 Windows 凭据（DPAPI）加密落盘；重启后登录一次，全部自动恢复，无需重输。

密钥的生命周期

01

保存即加密

设置里填入密钥，内存中保留明文供调用，磁盘上只写入绑定当前 Windows 用户的 DPAPI 密文。

02

重启后内存为空

进程重启，内存清空；磁盘密文保留，等待下次登录解密。

03

登录自动恢复

登录（或注册）时解密所有已保存的密文回内存，立刻可用。

04

登出即清空

登出会抹掉内存里的所有密钥；磁盘密文不动，下次登录再恢复。

安全属性

明文只在内存

磁盘与配置文件中只有密文，local.json 里搜索不到任何明文密钥。

绑定 Windows 用户

DPAPI 密文只对当前 Windows 账号可解，其他账号或另一台机器拿到文件也无法解开。

登出即清空

登出清空内存密钥；进程重启后内存同样为空，密钥不会残留。

可主动清除

设置里点「×」清除后不再恢复；删除某个服务商时，它的密文也会同步删除。
